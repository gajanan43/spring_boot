# Annotations:
1) @componet ->  Marks a class as a Spring-managed bean (i.e., a component automatically detected during component scanning).
2) @Autowired ->  Performs Dependency Injection (DI) automatically — Spring injects the required bean where it’s needed.
3) @Primary ->  If multiple beans of the same type exist, Spring will use the one marked as primary by default.
4) @Qulifier("/Class_Name") ->  Used to choose a specific bean when multiple beans of the same type exist.
